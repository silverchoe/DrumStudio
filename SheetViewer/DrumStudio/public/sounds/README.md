# 메트로놈 사운드 교체 방법

이 폴더에 다음 이름으로 `.wav` (또는 `.mp3`, `.ogg`) 파일을 넣으면 메트로놈이 자동으로 그 소리를 사용합니다.

| 파일명 | 용도 |
|---|---|
| `accent.wav` | 강박 (마디 첫 박) |
| `beat.wav`   | 약박 (그 외 메인 비트) |
| `sub.wav`    | 서브디비전 (8비트/16비트/3연음의 사이 박) |

## 동작 규칙
- 파일이 있으면 → 해당 파일 재생
- 파일이 없으면 → 기본 sine 클릭 (fallback)
- 음량은 `src/constants.js`의 `CLICK_GAIN`에서 조정

## 권장 사양
- **길이**: 50~150ms (너무 길면 다음 비트와 겹침)
- **포맷**: `.wav` 또는 `.mp3`
- **샘플레이트**: 44.1kHz 또는 48kHz

## 적용 방법
1. 파일을 이 폴더에 복사
2. 개발 중이면 브라우저 새로고침 (⌘+R)
3. 빌드된 앱이면 `npm run build` 후 다시 패키징
